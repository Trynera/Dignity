# Dignity

Experimental DiamondFire Text Programming Language.
Horribly crafted in Odin!

# Language Design

## Variables

Variables in Dignity are defined like this:

```jai
const1 :: 13.0;
const2 : num : 54;

var1 := 'Hello';
var2 : str = s"DF";
```

## Core Types

Dignity's core types are constraint to:

```js
num
txt
str
loc
vec
pot
sound
particle
item
any
list<>
dict<>
```
